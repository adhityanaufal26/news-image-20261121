A cream newspaper front page summing up Saturday 21 November 2026 in one 1024×1024 image: Peru's M6.7 quake at 00:09 UTC, COP31 running into Saturday overtime in Antalya, and KL Rahul's century on Day 3 in Wellington lead 32 dated stories with a UTC timeline, region counts, the day in numbers, a world map with numbered pins inside the continents, and a date-check box listing earlier stories left out on purpose. Friday events appear only as labelled aftermath or fallout reported today. All drawings are original Pillow vector-style illustrations.

## Run it

`python3 main.py` copies `entry.png` to `/output` (set `MAKEFUN_OUTPUT_DIR` locally to choose another directory). `python3 build_image.py` redraws `entry.png` deterministically with Pillow.
